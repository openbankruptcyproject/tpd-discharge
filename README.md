# tpd-discharge.openbankruptcyproject.org

**Total & Permanent Disability (TPD) Discharge**

Educational reference on the administrative TPD discharge program operated by the U.S. Department of Education for federal student loans. An alternate path to discharge that does not require a bankruptcy filing.

Live site: <https://tpd-discharge.openbankruptcyproject.org/>

Maintained by the [Open Bankruptcy Project](https://openbankruptcyproject.org/), a 501(c)(3) public charity (EIN 41-5159631).
